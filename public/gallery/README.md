# Public gallery samples

Synthetic square avatars used on the homepage, README, generate-page sample
tiles, and the landscape social card (`public/og.jpg`). They are **sample looks**,
not identity-preservation evidence.

- Provenance: generated 2026-08-13 as fictional adults / a fictional corgi mascot.
  No real user photos.
- License: CC0-1.0
- `public/og.jpg` is a 1200×630 collage of these stills for Open Graph / Twitter.
  GitHub repo social preview is a separate Settings upload; maintainers can use
  the same file.
- Do not copy gitignored `avatar-eval-results/` into this folder.
