## Title

Show HN: Simi Avatar – studio-quality avatars from text or a photo (BYOK)

## Body

Simi Avatar is an open-source workspace for square avatars: LinkedIn-style headshots, stylized portraits, and small team packs.

You describe a look or restyle a photo. Generation uses **your** OpenAI, MiniMax, fal.ai, or xAI key. The key stays in the browser session, passes through the server only for that request, and is never stored. No login, no database, no subscription.

Live demo: https://avatar.simi.studio
Source: https://github.com/simi-studio/avatar (MIT)

The public demo is the same BYOK app. There is no hosted free-credit trial. Self-host with `npm run dev` or the Cloudflare Workers path in the README.

Sample looks on the homepage are synthetic stills from the same generate flow, not a likeness guarantee and not user photos.

## What not to claim

- Do not invent user counts, waitlists, revenue, or “thousands of avatars generated.”
- Do not say the hosted demo includes free generations, credits, or a Simi-paid API key.
- Do not claim photographic identity match or that sample looks are real people.
- Do not compare win rates against Midjourney, Aragon, or other products without published evidence.
- Do not imply an X Premium+ subscription is an xAI API key.
